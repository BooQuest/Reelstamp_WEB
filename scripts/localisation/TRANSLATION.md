# 재사용할 영어 템플릿 번역 지침

입력 JSON의 source는 수정사항이 반영된 최신 한국어 원본입니다. source를 그대로 보존하고 translation만 작성하세요. 번역 실행은 사람이 요청한 번역 작업에서 수행하며 이 도구가 AI API를 호출하지는 않습니다.

- 자연스럽고 간결한 영국식 영어를 사용합니다. 고유명사는 공식 표기를 유지합니다.
- 템플릿은 template, 컷은 shot, 촬영 가이드는 filming guide, 기본 자막은 default caption으로 통일합니다.
- 가이드는 사용자가 바로 따라 할 수 있는 동작 중심 문장으로, 자막은 영상에서 읽기 쉬운 짧은 문장으로 작성합니다.
- template ID, cut ID, 컷 순서, 촬영 방식, 길이, 권한, BGM 등 공통 구조를 변경하거나 번역 객체에 추가하지 않습니다.
- `{product}` 같은 변수 이름·개수와 원문의 줄바꿈 개수를 보존합니다. 줄바꿈 위치의 의미도 검토합니다.
- 제목·설명·태그·컷 제목·가이드·기본 자막·카테고리 설명을 빠짐없이 번역합니다.
- 한국어가 포함된 썸네일, 가이드 이미지, 예시·고정 영상과 미리보기는 영어 자산으로 교체합니다. 언어 중립 자산은 검토 후 같은 URL을 명시합니다. URL을 추측해서 만들지 않습니다.
- 의도적으로 한국어 고유명사를 남길 경우 그 필드의 전체 문자열을 properNameExceptions에 기록하고 검토 결과에 이유를 남깁니다.
- sourceHash는 도구로 산출한 값만 사용합니다. 원문이 변경되면 이전 번역을 재검토하고 지문을 갱신합니다.
- review.translation, review.assets는 실제 검토를 마치기 전에는 false입니다. 자산 URL이 유효하다는 이유만으로 assets를 true로 표시하지 않습니다.

결과는 example.bundle.json 형식의 JSON으로 반환합니다. SQL은 직접 작성하지 말고 검증 도구로 생성합니다.
